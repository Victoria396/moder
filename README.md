# Модератор комментариев

Небольшое локальное Streamlit-приложение для пакетной проверки Excel-выгрузок с комментариями. ИИ и общее хранилище не используются: каждый запуск работает только с загруженными в текущий сеанс файлами.

## Запуск на компьютере

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

## Поддерживаемая структура Excel

Нужны колонки `ID`, `Оценка`, `Комментарий`, `Объект`, `Кем создан`, `Создан`. В `Объект` ожидается JSON с полем `id`, в `Кем создан` — JSON с `id` (или `email` как запасной идентификатор).

## Проверки

- Один и тот же пользователь и объект: первый комментарий по времени остаётся, последующие блокируются независимо от текста.
- Пустые комментарии и стандартные заполнители.
- Ссылки.
- Словарь запрещённых слов, который вводится в приложении.
- Явные формулировки жалоб и негативных отзывов.
- Подозрительные бессвязные строки помечаются эвристически.

Результат можно скорректировать в таблице перед выгрузкой. В приложении показываются общая таблица и отдельная таблица комментариев к блокировке; в обеих видны оценка и текст отзыва. Excel-отчёт содержит полный список и отдельный лист с рекомендациями к блокировке, также с оценкой и комментарием. Для чтения используется `openpyxl`, для создания отчёта — `xlsxwriter`.

## Публикация

Для публикации в Streamlit Community Cloud загрузите эти файлы в GitHub-репозиторий и выберите `app.py` как главный файл приложения. Бесплатное облачное размещение имеет лимиты размера и ресурсов; загружаемые таблицы не сохраняются приложением между сеансами.
